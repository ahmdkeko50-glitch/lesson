# أنشطة العلوم التفاعلية — السادس الابتدائي

Eight standalone interactive activities built from the Grade 6 science book (العلوم — السادس الابتدائي).
Each activity is **one HTML file**. Open it by double-clicking: there is no server, no internet and no install.
Open `index.html` to see all eight on one launcher page.

| File | Activity | Book location |
|---|---|---|
| `01-seed-germination.html` | داخلَ البذرةِ (Inside the seed) | Ch. 1 · Lesson 1, Reproduction by seeds |
| `02-potato-tuber.html` | مزرعةُ الدرناتِ (Tuber farm) | Ch. 1 · Lesson 2, Vegetative reproduction |
| `03-skin-explorer.html` | رحلةٌ داخلَ الجلدِ (Inside the skin), 3D | Ch. 4 · Lesson 2, Structure and functions of the skin |
| `04-nervous-system.html` | مركزُ القيادةِ (The brain at work) | Ch. 3 · Lesson 1, The nervous system |
| `05-atom-builder.html` | أبني ذرّتي (Build my atom), 3D | Ch. 5 · Lesson 1, The atom |
| `06-molecule-lab.html` | مختبرُ الجزيئاتِ (Molecule lab), 3D | Ch. 5 · Lesson 2, Elements and compounds |
| `07-chemical-change-lab.html` | مختبرُ التغيّرِ (Change lab) | Ch. 6 · Lessons 1–2, Chemical reactions |
| `08-joints-muscles.html` | كيفَ أتحرّكُ؟ (How do I move?), 3D | Ch. 3 · Lessons 2–3, The skeletal and muscular systems |

- **Book analysis and activity selection:** `../docs/analysis.md`.
- **Shared design base** that each activity was started from: `_base/base.html`.
- **Content sources:** facts are taken only from the book. Anything shown for the activity that is not in the book is labelled «توضيح للنشاط وليس من الكتاب».
